# Chosen Man Studio logo family

The Yorkshire rose is the master brand mark. Keep its geometry, clear space, and proportions consistent across every use.

## Background-specific assets

### Light backgrounds

- `chosen-man-primary-on-light.png` — full horizontal lockup for bone, white, or pale neutral surfaces
- `chosen-man-emblem-on-light.png` — rifle-green rose with brass technical grid and interface detailing
- `chosen-man-mark-on-light.png` — compact rifle-green rose

### Dark backgrounds

- `chosen-man-primary-on-dark.png` — full horizontal lockup in bone and brass
- `chosen-man-emblem-on-dark.png` — brass rose with bone technical grid and interface detailing
- `chosen-man-mark-on-dark.png` — compact brass rose

All production files have transparent backgrounds. `chosen-man-logo-family-preview.png` is a reference sheet, not a production logo.

## Brand colours

- Ultra-dark: `#0B110E`
- Rifle green: `#1B2E23`
- Bone: `#F4F3EE`
- Brass: `#C5A059`

## Usage rules

- Use only the variant named for the surface beneath it.
- Keep clear space around the logo equal to at least the diameter of the rose's centre ring.
- Do not add shadows, bevels, gradients, outlines, or recolour individual petals.
- Use the horizontal lockup when the company name must be explicit.
- Use the technical-grid emblem for profile images, covers, presentation titles, and formal brand moments.
- Use the compact rose for favicons, app icons, social avatars, and small interface placements.
